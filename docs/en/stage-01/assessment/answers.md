Answers and explanations

1. Computer Architecture and Components

 #   ✓   Answers and explanations

 1   C   Normal RAM is volatile; SSD/HDD and USB flash memory retain stored data.

 2   B   A CPU executes instructions; it does not replace persistent storage or the
         monitor.

 3   A   An SSD generally provides faster access, especially to small scattered files.

 4   C   RAM is temporary working memory, distinct from disk capacity.

 5   B   The GPU specializes in graphics and parallel workloads.

 6   D   Performance also depends on architecture, core count and the software
         workload.


7. Suggested response: RAM holds active program data while the computer
runs; persistent storage retains documents after shutdown.

8. Suggested response: CPU for compiling, RAM for IDE/browser, SSD for
project access and screen/battery for comfortable work; other justified
factors are acceptable.


2. Operating Systems and Windows 11

 #   ✓   Answers and explanations

 1   B   The OS shares resources and offers services needed by programs.

 2   A   A running program instance is a process.

 3   C   Task Manager includes resource observations by process.

 4   B   Drivers enable communication with hardware.

 5   D   Unfamiliar components require identification before intervention.

 6   A   Stored instructions and a running process are different concepts.


7. Suggested response: The Windows Time service may synchronize the
clock without showing a window.

8. Suggested response: An update may replace files currently in use, so a
restart safely completes installation.

3. Files, Folders and File Systems

 #   ✓   Answers and explanations

 1   B   An absolute path starts at a known root.

 2   C   Renaming does not convert the internal file format.

 3   A   Copying preserves the original.

 4   D   NTFS is a file system; the other options are file extensions.

 5   B   Visible extensions expose actual file naming more clearly.

 6   C   ZIP can package multiple files and compress them.


7. Suggested response: PDF is a document format; NTFS is how a storage
volume organizes files.

8. Suggested response: For example input/ for originals, working/ for
edits, result/ for finished work and backup/ for copies.


4. Software Installation and Configuration

 #   ✓   Answers and explanations

 1   D   Official distribution usually reduces tampering risk.

 2   B   Portable software may run without traditional system installation.

 3   A   UAC requires understanding and verification before elevation.

 4   C   Successful setup is confirmed by launching and exercising functionality.

 5   B   The license regulates authorized use.

 6   D   Use supported uninstall procedures and protect user data.


7. Suggested response: Installation places/configures application files;
activation validates use rights under a licensing scheme.

8. Suggested response: Unexpected administrator rights, a request to
disable protection, unknown publisher, bundled software or a suspicious
download address.

6. Computer Diagnostics and Troubleshooting

 #   ✓   Answers and explanations

 1   D   Gather symptoms and evidence before changing the system.

 2   B   High CPU means the CPU is busy at that moment.

 3   A   Timing helps assess whether a log entry is relevant.

 4   C   Paging under heavy memory pressure can slow work.

 5   D   Unverified cleanup claims are not evidence.

 6   B   Changing one variable improves causal reasoning.


7. Suggested response: Possible causes: slow connection (test other sites),
DNS resolution trouble (observe lookup), browser extension or remote
server load (compare browser/site).

8. Suggested response: Background errors may be unrelated; correlate
time, source, frequency and reproducibility before interpreting.


7. Archives, Backups and Data Recovery

 #   ✓   Answers and explanations

 1   A   Independent storage reduces the risk of common physical failure.

 2   C   Restoring content is the essential usability test.

 3   B   The rule counts the original plus two additional copies.

 4   D   Incremental backup stores changes since the previous backup point.

 5   A   Synchronization can propagate deletions and mistakes.

 6   C   Matching SHA-256 hashes strongly indicate identical file content.

---

7. Suggested response: When an SSD fails, both originals and a ZIP on the
same SSD can disappear together.

8. Suggested response: Define files to protect, schedule, independent
locations, retention and regular restore testing; also consider encryption/
access rights.


8. Final Practical Workshop

 #   ✓   Answers and explanations

 1   B   The first step is understanding the user’s needs and initial environment.

 2   D   Source, license and compatibility are essential pre-install checks.

 3   A   Separating files supports reproducibility and protects originals.

 4   C   Restoring and opening real files verifies a backup.

 5   B   An isolated percentage without context is not enough for a hardware
         decision.

 6   D   A useful report records inputs, actions, evidence and limits.


7. Suggested response: Working OS, appropriate legitimate applications,
organized folders and proven backup recovery are examples.

8. Suggested response: Passwords, access tokens, product keys, account
IDs, private photos, device serial numbers and private addresses; exposure
can enable misuse.
