# Glossary, assessment and templates

Glossary — Stage 1

Term               Meaning

CPU                Central processing unit; executes instructions.

Core / thread      Hardware execution core / sequence of work within a program;
                   not synonymous.

RAM                Volatile working memory for active code and data.

SSD / HDD          Persistent flash / mechanical storage devices.

GPU                Graphics processor for parallel graphics and other supported
                   workloads.

Motherboard        Board connecting processor, memory, peripherals and
                   controllers.

Operating system   Software managing resources and supplying services to
                   applications.

Kernel             Privileged core of the operating system.

Driver             Software linking the OS and a hardware device.

Program /          Stored instructions / running program instance.
process

Service            Background OS/application functionality, often without a window.

UAC                Windows User Account Control; prompt for elevated operations.

ACL                Access-control list assigning permissions to users or groups.

NTFS / exFAT       File systems used on storage volumes.

File extension     Filename suffix such as .txt , .pdf or .exe .

ZIP                Archive format for bundling and optional compression.

Backup             Recoverable independent copy of important data.

Restore            Process of recovering usable data from a backup.

SHA-256            Cryptographic hash used as a file-content fingerprint.

Least privilege    Give only rights required for a task.

Troubleshooting    Gathering evidence, testing hypotheses and validating resolution.

Recommended completion threshold: 28/40, including mandatory safe
software handling and demonstrated restore verification. The rubric
evaluates training progress, not professional certification.

Self-check: eight lessons × six single-choice questions = 48; eight lessons
× two open questions = 16. Open responses are assessed for conceptual
accuracy rather than matching exact wording.
