# Computer Systems and Digital Literacy

Stage 1 — Computer Systems and Digital
Literacy
Eight individual lessons · approximately 12 guided hours · Windows 11.
Audience: beginners with basic computer use (upper-secondary school /
early university level).

This course develops practical knowledge of computers, Windows, files,
permissions, installation, diagnostics and backups. Each lesson includes
theory, six single-answer questions, two open-ended questions, guided
practice and homework. The answer key is collected at the end of Stage 1.


Safe practice rules

Only use test files in Documents/it-course/stage01 . Do not delete real files,
change protected settings, modify services/drivers or install software
without permission. Use official and licensed software. Never post
passwords, keys, serial numbers, personal information or private
screenshots to a public repository. On restricted computers, replace risky
changes with observation or teacher demonstrations.

Expected result: an inventory, organized practice files, a safe software
check, a diagnostic report, a verified restore, and a final workstation-
preparation report.
