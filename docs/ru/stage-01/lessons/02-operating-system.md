# 2. Операционные системы и Windows

Занятие 2. Операционные системы и
устройство Windows
Продолжительность: 90 минут · Результат: краткий отчёт о версии
Windows, приложениях, процессах и использовании ресурсов.


Цели

Ученик отличает аппаратное обеспечение, ОС и приложения, понимает
роль драйверов и файловой системы, различает процесс и программу,
умеет наблюдать за системой без опасных изменений настроек.


Теория

1. Что делает операционная система
ОС выступает посредником между программами и аппаратными
ресурсами. Она планирует выполнение задач CPU, распределяет
память, предоставляет файловую систему, обеспечивает работу
драйверов, управляет пользователями и устройствами ввода-вывода.
Без ОС компьютерное оборудование не превращается автоматически в
удобную рабочую среду. Windows, Linux, macOS и Android отличаются
интерфейсом и устройством, но решают общие классы задач.

2. Ядро, системные службы и пользовательские
приложения
Ядро ОС управляет критическими ресурсами. Службы — фоновые
компоненты, которые выполняют системные или прикладные задачи,
иногда без открытого окна. Приложение — программа, с которой
взаимодействует пользователь. Один продукт может запускать
несколько процессов, а процесс может включать несколько потоков.
Закрыть окно не всегда значит остановить все фоновые части
приложения.

3. Процесс и поток
Программа — набор инструкций, сохранённых на диске; процесс —
работающий экземпляр программы с выделенными ресурсами. Поток
— линия выполнения внутри процесса. Диспетчер задач показывает
процессы и их потребление CPU, памяти, диска, сети. Не следует
завершать незнакомые системные процессы: это может привести к
потере данных или нестабильности.

4. Память и многозадачность
ОС создаёт иллюзию одновременной работы множества программ с
помощью планирования. Когда приложение «зависло», причина может
быть в ожидании диска, сети, блокировке, нехватке памяти или

вычислительной перегрузке. Значение «100% CPU» говорит о текущей
загрузке в используемой метрике, а не автоматически о
неисправности. Перед диагностикой нужно зафиксировать симптомы.

5. Драйверы и устройства
Драйвер — программный компонент, который помогает ОС управлять
конкретным устройством. Устройства видны в Диспетчере устройств;
предупреждающий значок может указывать на проблему. Не нужно
автоматически обновлять все драйверы сторонними утилитами.
Предпочтительны Windows Update и официальная поддержка
производителя.

6. Выпуски, версии и обновления Windows
Windows 11 Home и Pro имеют различия в корпоративных функциях,
управлении и возможностях виртуализации. Номер сборки помогает
понять, какие функции доступны. Обновления закрывают уязвимости и
исправляют ошибки; установка может требовать перезапуска. Перед
крупным изменением важны сохранение открытых файлов и резервная
копия. Экранные пути могут меняться между выпусками.

7. Интерфейсы администрирования
Параметры — основной графический интерфейс настройки; Диспетчер
задач — наблюдение за процессами; Диспетчер устройств —
устройства и драйверы; Сведения о системе — технические сведения;
Просмотр событий — журнал диагностических сообщений. Командная
строка и PowerShell дают текстовый доступ к части функций, но в этом
этапе используются преимущественно наблюдательные действия.

8. Корректное завершение программ и перезагрузка
Сначала сохранить работу и закрыть программу обычным способом.
Если окно не отвечает — подождать, проверить активность, при
необходимости завершить только известное пользовательское
приложение, предварительно приняв риск потери несохранённой
работы. Перезагрузка — это стандартный диагностический приём, но
не замена выяснению причины повторяющейся проблемы.

Практикум на ПК

Задание A. Паспорт ОС (10 минут)

 1. Открой Параметры → Система → О системе, запиши выпуск и
   версию Windows.
 2. Win + R → winver : сравни данные со сведениями в Параметрах.
 3. Открой Параметры → Центр обновления Windows и посмотри
   статус, не запускай установку без разрешения.
 4. Заполни windows-report.md (можно создать по структуре ниже).

Задание B. Наблюдение за процессами (12 минут)

 1. Открой Блокнот, затем Диспетчер задач → Процессы.
 2. Найди Блокнот, запиши примерное использование памяти.
 3. Открой два окна Блокнота и посмотри, как они отображаются.
   Заметь, что число строк/процессов зависит от реализации ОС.
 4. Закрой Блокнот обычным способом и проверь изменения списка.

Задание C. Найти инструмент для задачи (8 минут)
По очереди открой Диспетчер устройств, Сведения о системе,
Просмотр событий. Для каждого запиши одну задачу, которую он
помогает решать. В Просмотре событий только просматривай записи;
не очищай журналы.

---

Задание D. Анализ автозагрузки без изменений (5 минут)
Посмотри Диспетчер задач → Автозагрузка приложений или
Параметры → Приложения → Автозагрузка. Выдели 1–2 приложения,
запуск которых, возможно, необязателен; объясни преподавателю
последствия отключения. Не отключай их, пока преподаватель не
согласует эксперимент.
