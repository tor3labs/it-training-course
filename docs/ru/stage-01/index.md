# Компьютерные системы и цифровая грамотность

Этап 1. Компьютерные системы и
цифровая грамотность
8 индивидуальных занятий · примерно 12 контактных часов · Windows
11.

Для обучающихся с базовыми навыками работы на ПК (уровень
старших классов школы или первых курсов университета).

Каждый урок включает теорию, шесть вопросов с выбором ответа, два
открытых вопроса, пошаговую практику на ПК и домашнее задание.
Все ответы на тесты и пояснения собраны в конце первого этапа.


Дополнительные материалы


Безопасность практикума

Используй только специально созданные учебные файлы в Документы/
it-course/stage01 . Не удаляй личные файлы и не меняй службы,
драйверы, реестр, права на системные папки или защиту ОС без
разрешения владельца. Скачивай приложения из официальных
источников и соблюдай лицензии. Не публикуй в GitHub пароли, ключи,
серийные номера, адреса и личные данные. При ограниченных правах
выполняй только наблюдательную часть упражнения или
демонстрацию преподавателя.

Ожидаемый результат этапа: технический паспорт, организованная
структура файлов, проверка установки и прав, отчёт о диагностике,
проверенное восстановление копии и итоговый отчёт по подготовке
компьютера.
