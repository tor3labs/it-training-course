# Բառարան, չափանիշներ և ձևանմուշներ

Տերմինների բառարան

Տերմին               Բացատրություն

CPU                  Կենտրոնական պրոցեսոր, կատարում է ծրագրերի
                     հրահանգները։

Միջուկ / հոսք        Հաշվարկային բաղադրիչ / ծրագրի կատարվող
                     աշխատանքի հաջորդականություն։

RAM                  Օպերատիվ հիշողություն ընթացիկ ծրագրերի համար։

SSD / HDD            Երկարաժամկետ ֆլեշ / մեխանիկական
                     պահեստավորման սարքեր։

GPU                  Գրաֆիկական և որոշ զուգահեռ հաշվարկների
                     պրոցեսոր։

Մայր սալիկ           Կապում է պրոցեսորը, հիշողությունը և սարքերը։

Օպերացիոն համակարգ   Կառավարում է համակարգչի ռեսուրսներն ու
                     ծառայությունները։

Միջուկ (kernel)      ՕՀ-ի արտոնյալ կառավարման հիմնական մաս։

Դրայվեր              ՕՀ-ի և սարքի միջև փոխգործակցությունն ապահովող
                     ծրագիր։

Ծրագիր / գործընթաց   Պահված հրահանգներ / դրանց գործարկված օրինակ։

Ծառայություն         Հետին պլանում կատարվող համակարգային
                     գործառույթ։

UAC                  Windows-ի բարձրացված իրավունքների հաստատման
                     մեխանիզմ։

ACL                  Օգտատերերի և խմբերի մուտքի թույլտվությունների
                     ցուցակ։

NTFS / exFAT         Կրիչի ֆայլային համակարգեր։

Ընդլայնում           Ֆայլանվան վերջավորություն, օրինակ՝ .pdf կամ
                     .exe ։

ZIP                  Ֆայլերի փաթեթավորման և սեղմման ձևաչափ։

Պահուստավորում       Կարևոր տվյալների վերականգնելի անկախ պատճենի
                     ստեղծում։

Վերականգնում         Պահուստից տվյալների կրկին ստացում։

SHA-256              Ֆայլի պարունակության թվային մատնահետք
                     ստեղծող hash ալգորիթմ։

Նվազագույն           Տրամադրել միայն անհրաժեշտ իրավունքները։
արտոնություններ

Ախտորոշում           Փաստերի հավաքում և վարկածների ստուգում։

                                            հաշվետվություն

 Ընդամենը                              40


Առաջարկվող հաջողության շեմը՝ առնվազն 28/40 միավոր՝ ծրագրերի
անվտանգ օգտագործման և պահուստից վերականգնման պարտադիր
ցուցադրմամբ։ Գնահատումը ուսումնական է, ոչ պետական
որակավորում։

Ինքնաստուգում՝ 8 դաս × 6 թեստային հարց = 48, 8 դաս × 2 բաց հարց
= 16։ Բաց հարցերի պատասխանները գնահատվում են
բովանդակությամբ, ոչ բառացի համընկնմամբ։
