# 1. Համակարգչի կառուցվածքը

1. Համակարգչի կառուցվածքը և
հիմնական բաղադրիչները
Տևողություն: 90 min · Արդյունք: համակարգչի բնութագրերի
հաշվետվություն և հիմնավորված ընտրություն


Ուսուցման արդյունքներ

Բացատրել սարքավորումների և ծրագրերի փոխգործակցությունը,
ճանաչել հիմնական բաղադրիչները, Windows 11-ում գտնել համակարգչի
բնութագրերը և տարբերել չափված տվյալները ենթադրություններից։


Տեսություն և օրինակներ

1. Համակարգիչը որպես տեղեկատվության մշակման
համակարգ
Համակարգիչը ստանում է տվյալներ ստեղնաշարից, մկնիկից, ցանցից
կամ այլ սարքերից, մշակում է դրանք ծրագրերի հրահանգներով և
ներկայացնում արդյունքը էկրանին, ֆայլում կամ ցանցով։
Սարքավորումը և ծրագրային ապահովումը աշխատում են միասին։
Համակարգի արագությունը կախված է ոչ միայն պրոցեսորից, այլև
հիշողությունից և պահեստավորման սարքերից։ Օրինակ՝ օպերատիվ
հիշողության պակասը կարող է դանդաղեցնել նույնիսկ հզոր
համակարգիչը։


                       RAM

      INPUT            CPU                 GPU            OUTPUT

  keyboard, network                   visual processing   screen, file

                      SSD/HDD

2. CPU՝ կենտրոնական պրոցեսոր
CPU-ն կատարում է ծրագրերի մեքենայական հրահանգները՝
հաշվարկներ, համեմատություններ և տվյալների փոխանցումներ։
Միջուկը հաշվարկներ կատարող բաղադրիչ է։ Ծրագրային հոսքը և
ապարատային տրամաբանական պրոցեսորը տարբեր
հասկացություններ են։ ԳՀց-ով չափվող հաճախականությունը ինքնին
բավարար չէ պրոցեսորների արագությունը համեմատելու համար.
կարևոր են նաև ճարտարապետությունը, միջուկների քանակը,
հիշապահեստը և առաջադրանքի բնույթը։

---

3. RAM՝ օպերատիվ հիշողություն
RAM-ում պահվում են տվյալ պահին աշխատող ծրագրերի տվյալներն ու
հրահանգները։ Սովորական RAM-ը էներգաանկախ չէ.
հոսանքազրկվելուց հետո դրա պարունակությունը կորչում է։ Մեծ ծավալն
օգնում է միաժամանակ գործարկել մի քանի ծրագիր, սակայն միշտ չէ,
որ արագացնում է ցանկացած գործողություն։ RAM-ի պակասի դեպքում
Windows-ը կարող է տվյալների մի մասը տեղափոխել սկավառակ, ինչը
սովորաբար ավելի դանդաղ է։

4. SSD, HDD և երկարաժամկետ պահեստավորում
SSD-ն ու HDD-ն պահպանում են ֆայլերը նաև համակարգիչն
անջատելուց հետո։ HDD-ն ունի մեխանիկական պտտվող մասեր, իսկ
SSD-ն՝ ֆլեշ հիշողություն։ SSD-ն սովորաբար արագ է պատահական
ընթերցումների դեպքում և հաճախ արագացնում է ծրագրերի մեկնարկը։
Տարողությունը և արագությունը տարբեր բնութագրեր են։ Գովազդային
GB-ի և օպերացիոն համակարգում ցուցադրվող GiB-ի տարբերությունը
կարող է փոխել թվային ցուցանիշը։

5. GPU և պատկերների մշակում
GPU-ն նախատեսված է բազմաթիվ զուգահեռ հաշվարկների համար,
հատկապես՝ երկչափ և եռաչափ գրաֆիկայում։ Ներկառուցված GPU-ն
հաճախ օգտագործում է ընդհանուր համակարգային ռեսուրսներ, իսկ
դիսկրետ GPU-ն ունի առանձին հաշվարկային բաղադրիչ և հաճախ՝
սեփական տեսահիշողություն։ Մոնիտորը ցուցադրում է պատկերը, բայց
ինքը չի հաշվարկում այն։ Սովորական գրասենյակային աշխատանքի
համար դիսկրետ GPU միշտ չէ, որ անհրաժեշտ է։

6. Մայր սալիկ, միակցիչներ և սնուցում
Մայր սալիկը կապում է պրոցեսորը, հիշողությունը, պահեստավորումը և
արտաքին սարքերը։ USB, HDMI, Ethernet և այլ միակցիչները տարբեր
նպատակներ ունեն։ Միատեսակ արտաքին ձև ունեցող միակցիչները
պարտադիր չէ, որ աջակցեն նույն հնարավորություններին կամ
արագություններին։ Սնուցման բլոկը տրամադրում է էներգիա, իսկ
հովացման համակարգը օգնում է վերահսկել ջերմաստիճանը։
Գերտաքացումը կարող է նվազեցնել արտադրողականությունը։

7. Մուտքային ու ելքային սարքեր և դրայվերներ
Ստեղնաշարը և խոսափողը հիմնականում մուտքային սարքեր են,
էկրանը և բարձրախոսները՝ ելքային, իսկ սենսորային էկրանը կարող է
կատարել երկու դեր։ Դրայվերը օպերացիոն համակարգին թույլ է տալիս
աշխատել կոնկրետ սարքի հետ։ Անհամատեղելի կամ բացակայող
դրայվերը կարող է խանգարել սարքի ճիշտ աշխատանքին։ Անծանոթ
«դրայվերների թարմացման» ծրագրեր տեղադրելուց առաջ պետք է
ստուգել դրանց աղբյուրը։

---

8. Համակարգչի ընտրությունը ըստ աշխատանքի
Սովորելու և գրասենյակային աշխատանքի համար կարևոր են SSD-ն,
բավարար RAM-ը, հարմար էկրանը և ստեղնաշարը։ Ծրագրավորման
համար կարող են պետք գալ ավելի շատ հիշողություն և պրոցեսորի
ռեսուրսներ։ Եռաչափ գրաֆիկայի համար կարևոր են GPU-ն և
հովացումը։ Ընտրելիս անհրաժեշտ է գնահատել գինը, ծրագրերի
պահանջները, վերանորոգելիությունը և իրական օգտագործման
սցենարը։


Գիտելիքների ստուգում

1–6 հարցերից յուրաքանչյուրի համար ընտրեք մեկ ճիշտ պատասխան։
7–8 հարցերին պատասխանեք ձեր բառերով։ Բացատրություններով
պատասխանները ներկայացված են առաջին փուլի վերջում։

 1. Ո՞ր բաղադրիչը սովորաբար կորցնում է տվյալները հոսանքն
    ամբողջությամբ անջատելիս։ A) SSD B) HDD C) RAM D) USB ֆլեշ
    կրիչ

 2. Ո՞րն է CPU-ի հիմնական գործառույթը։ A) Անմիջապես պատկեր
    ցուցադրել էկրանին B) Կատարել ծրագրի հրահանգները C)
    Մշտապես պահել փաստաթղթերը D) Էլեկտրական սնուցում
    ապահովել

 3. Ինչո՞ւ SSD-ն հաճախ ավելի արագ է գործարկում ծրագրերը, քան
    HDD-ն։ A) Տվյալներին հասանելիության ուշացումը սովորաբար
    ավելի փոքր է B) Միշտ ունի ավելի մեծ տարողություն C)
    Փոխարինում է CPU-ին D) Պարունակում է GPU

 4. Ի՞նչ է բնութագրում RAM-ի ծավալը։ A) Ինտերնետի արագությունը
    B) Սկավառակի առավելագույն չափը C) Աշխատանքային
    հիշողության ծավալը D) Էկրանի թարմացման հաճախականությունը

 5. Ո՞ր բաղադրիչն է հատկապես կարևոր բարդ 3D գրաֆիկայի
    համար։ A) Քարտընթերցիչը B) GPU-ն C) Խոսափողը D) Ցանցային
    մալուխը

 6. Ինչո՞ւ բավարար չէ CPU-ները համեմատել միայն ԳՀց-ով։ A)
   Հաճախականությունը վերաբերում է միայն ձայնին B) Բոլոր
   պրոցեսորները նույն աշխատանքն են կատարում մեկ տակտում C)
   Այն ցույց է տալիս RAM-ի ծավալը D) Կարևոր են նաև
   ճարտարապետությունը, միջուկները և առաջադրանքը

 7. Երկու նախադասությամբ բացատրեք RAM-ի և SSD/HDD-ի
    տարբերությունը։

 8. Նշեք ծրագրավորման համար նոութբուք ընտրելու չորս բնութագիր և
    հիմնավորեք ընտրությունը։

Գործնական աշխատանք համակարգչով

A. Ա. Համակարգչի բնութագրերի ուսումնասիրություն

 1. Բացեք Start → Settings → System → About և գրանցեք CPU-ի մոդելը,
    RAM-ի ծավալը, Windows-ի տարբերակը և համակարգի
    ճարտարապետությունը։
 2. Սեղմեք Win + R, գործարկեք msinfo32 և գտնեք սարքի արտադրողը/
    մոդելը, եթե դրանք ցուցադրվում են։
 3. Լրացրեք նյութերի մեջ տրված համակարգչի բնութագրերի
    ձևանմուշը։ Մի հրապարակեք սերիական համարներ, սարքի ID կամ
    լիցենզիայի բանալիներ։

Կատարման չափանիշներ: Տվյալները ստուգելի են Windows-ում,
անձնական նույնացուցիչներ չեն հրապարակվել։

B. Բ. Ռեսուրսների դիտարկում

 1. Բացեք Task Manager-ը՝ Ctrl + Shift + Esc, և ընտրեք Performance
    բաժինը։
 2. Դիտեք CPU, Memory, Disk և GPU ցուցանիշները (եթե առկա են)։
 3. Գրանցեք ցուցանիշները հանգիստ վիճակում և սովորական ծրագիր
    բացելիս, ապա գրեք երկու եզրակացություն։

Կատարման չափանիշներ: Տարբերակվում են ընթացիկ
ծանրաբեռնվածությունն ու սարքի ընդհանուր հզորությունը։

C. Գ. Համեմատական ընտրություն

 1. Համեմատեք A՝ 4 միջուկ, 8 GB RAM, HDD 1 TB; B՝ 6 միջուկ, 16 GB
    RAM, SSD 512 GB; C՝ 8 միջուկ, 16 GB RAM, SSD 1 TB, դիսկրետ GPU։ A-
    ն ամենաէժանն է, B-ն՝ C-ից էժան։
 2. Ընտրեք տարբերակ գրասենյակի, ծրագրավորման և 3D գրաֆիկայի
    համար՝ յուրաքանչյուրի համար բերելով առնվազն երկու պատճառ։
 3. Նշեք, թե ինչ լրացուցիչ տեղեկություն է անհրաժեշտ վերջնական
    ընտրության համար։

Կատարման չափանիշներ: Ընտրությունը հիմնավորված է, թվային
բարձր ցուցանիշը ինքնանպատակ չէ։

Տնային աշխատանք

Ներկայացրեք համակարգչի բնութագրերի հաշվետվությունը, A/B/C
տարբերակների համեմատությունը և 5–7 նախադասություն ձեր
համակարգչի հնարավոր արդիականացման մասին։

Լրացուցիչ առաջադրանք: Բացատրեք, թե ինչու ավելի քիչ միջուկներով
CPU-ն երբեմն կարող է արագ կատարել մեկ հոսքով ծրագիր։
