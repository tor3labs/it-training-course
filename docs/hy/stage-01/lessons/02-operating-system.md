# 2. Օպերացիոն համակարգեր և Windows

2. Օպերացիոն համակարգեր և
Windows 11
Տևողություն: 90 min · Արդյունք: օպերացիոն համակարգի և
գործընթացների համառոտ հաշվետվություն


Ուսուցման արդյունքներ

Տարբերակել սարքավորումը, օպերացիոն համակարգը, ծրագիրը,
գործընթացը, դրայվերն ու ծառայությունը և անվտանգ ուսումնասիրել
Windows 11-ի հիմնական գործիքները։


Տեսություն և օրինակներ

1. Օպերացիոն համակարգի նշանակությունը
Օպերացիոն համակարգը (ՕՀ) կառավարում է պրոցեսորի ժամանակը,
հիշողությունը, սարքերը, ֆայլերը, օգտատերերին և ցանցը։ Այն
ծրագրերին տրամադրում է աշխատանքային միջավայր և
ծառայություններ։ Windows-ը, Linux-ը և macOS-ը ՕՀ-ների օրինակներ են։
ՕՀ-ն չի փոխարինում բրաուզերին կամ տեքստային խմբագրիչին․ դրանք
առանձին ծրագրեր են։

2. Միջուկ և օգտատիրական ծրագրեր
ՕՀ-ի միջուկը իրականացնում է համակարգի հիմնական կառավարման
արտոնյալ գործողությունները։ Օգտատիրական ծրագրերը սովորաբար
աշխատում են սահմանափակ իրավունքներով և անհրաժեշտության
դեպքում դիմում են ՕՀ-ին։ Այս բաժանումն օգնում է նվազեցնել սխալների
հնարավոր վնասը։ Սակայն այն չի վերացնում թարմացումների և
պահուստավորման անհրաժեշտությունը։

3. Ծրագիր, գործընթաց և հոսք
Ծրագիրը սկավառակում պահվող հրահանգների և ռեսուրսների
ամբողջություն է։ Գործընթացը գործարկված ծրագրի օրինակն է, որի
համար հատկացվում են ռեսուրսներ։ Մեկ ծրագիրը կարող է ունենալ մի
քանի գործընթաց, իսկ գործընթացը՝ մի քանի հոսք։ Անծանոթ անունով
գործընթացը պարտադիր չէ, որ վնասակար լինի։

4. Սարքային դրայվերներ
Դրայվերը միջնորդում է ՕՀ-ի և կոնկրետ սարքի փոխգործակցությունը։
Windows-ը կարող է ինքնուրույն տեղադրել համապատասխան
դրայվերներ, բայց բոլոր լրացուցիչ հնարավորությունները միշտ չէ, որ
հասանելի են։ Device Manager-ում նախազգուշացումը կարող է ցույց տալ
խնդիր։ Առաջնահերթ ստուգեք Windows Update-ը և սարքի արտադրողի
պաշտոնական կայքը։

---

5. Ռեսուրսների բաշխում
Windows-ը տարբեր գործընթացների միջև բաշխում է պրոցեսորի
ժամանակն ու հիշողությունը։ Task Manager-ում ցուցադրվող տոկոսները
տվյալ պահի չափումներ են։ Հիշապահեստավորված RAM-ը միշտ չէ, որ
«վատնած» հիշողություն է։ Թարմացումները և ֆոնային սպասարկումը
կարող են ժամանակավորապես օգտագործել ռեսուրսներ։

6. Ծառայություններ և ավտոմատ մեկնարկ
Ծառայությունները հաճախ աշխատում են հետին պլանում՝ առանց
առանձին պատուհանի։ Դրանք ապահովում են ցանցային, ժամանակի,
տպման և այլ գործառույթներ։ Startup ծրագրերը կարող են ավտոմատ
մեկնարկել մուտք գործելիս։ Անծանոթ ծառայությունը կասեցնելը կարող
է խաթարել համակարգի աշխատանքը, ուստի այս դասին դրանք միայն
ուսումնասիրում ենք։

7. Թարմացումներ և վերագործարկում
Թարմացումները կարող են շտկել անվտանգության և կայունության
խնդիրներ։ Որոշ համակարգային ֆայլեր գործածության ընթացքում
փոխարինել հնարավոր չէ, այդ պատճառով պահանջվում է
վերագործարկում։ Թարմացումից առաջ պահպանեք բաց
փաստաթղթերը։ Առանց պատճառի մի անջատեք համակարգիչը
թարմացման ընթացքում։

8. Windows 11-ի ուսումնասիրման գործիքները
Settings → System → About բաժնում կարելի է տեսնել Windows-ի
թողարկումը և սարքի հիմնական բնութագրերը։ winver հրամանը ցույց է
տալիս տարբերակն ու build-ը, msinfo32 -ը՝ համակարգային
տեղեկությունը, Task Manager-ը՝ գործընթացների ակտիվությունը։ Home
և Pro թողարկումների որոշ կառավարման գործառույթներ տարբեր են։


Գիտելիքների ստուգում

1–6 հարցերից յուրաքանչյուրի համար ընտրեք մեկ ճիշտ պատասխան։
7–8 հարցերին պատասխանեք ձեր բառերով։ Բացատրություններով
պատասխանները ներկայացված են առաջին փուլի վերջում։

 1. Ո՞րն է օպերացիոն համակարգի հիմնական խնդիրը։ A) Միայն
    պատուհաններ նկարել B) Կառավարել ռեսուրսները և
    ծառայություններ տալ ծրագրերին C) Փոխարինել բոլոր ծրագրերը D)
    Աշխատել միայն ինտերնետով

 2. Ի՞նչ է գործընթացը (process)։ A) Ծրագրի գործարկված օրինակը B)
    Միայն սկավառակի .exe ֆայլը C) Սկավառակի բաժինը D)
    Ստեղնաշարի կոճակը

 3. Ի՞նչ կարելի է սովորաբար տեսնել Task Manager-ում։ A) Միայն
    սենյակի ջերմաստիճանը B) Միայն համակարգչի պատյանի մոդելը

---

C) Գործընթացների CPU/RAM օգտագործումը D) Լիցենզիաների
   գաղտնի բանալիները

 4. Ինչի՞ համար է անհրաժեշտ դրայվերը։ A) Լուսանկարներ պահելու
    B) Կոնկրետ սարքի հետ հաղորդակցվելու C) Սնուցման բլոկը
    փոխարինելու D) Արխիվները սեղմելու

 5. Ի՞նչ անել, եթե անծանոթ գործընթացը ծանրաբեռնում է
    համակարգիչը։ A) Անմիջապես ավարտել գործընթացը B) Ջնջել
    Windows պանակը C) Անջատել պաշտպանությունը D) Սկզբում
    պարզել դրա նշանակությունը և հավաքել փաստեր

 6. Ինչո՞վ է ծրագիրը տարբերվում գործընթացից։ A) Ծրագիրը
    պահված հրահանգներն են, գործընթացը՝ դրանց կատարվող
    օրինակը B) Գործընթացներ ունեն միայն խաղերը C) Գործընթացը
    միշտ սարք է D) Դրանք ցանկացած ֆայլի հոմանիշներն են

 7. Բերեք Windows ծառայության օրինակ և բացատրեք՝ ինչու այն
    կարող է աշխատել առանց պատուհանի։

 8. Ինչո՞ւ է թարմացումից հետո երբեմն անհրաժեշտ վերագործարկել
    համակարգիչը։


Գործնական աշխատանք համակարգչով

A. Ա. Windows-ի տարբերակի որոշում

 1. Սեղմեք Win + R, գրեք winver և գրանցեք ցուցադրվող տարբերակը։
 2. Բացեք Settings → System → About և նշեք թողարկումը,
    ճարտարապետությունը և RAM-ի ծավալը։
 3. msinfo32 -ով ուսումնասիրեք համակարգային տեղեկությունները․
    անհասանելի տվյալների փոխարեն գրեք «անհայտ»։

Կատարման չափանիշներ: Տեղեկությունը վերցված է իրական
համակարգային գործիքներից։

B. Բ. Գործընթացի դիտարկում

 1. Բացեք Task Manager → Processes և գտեք ծանոթ ծրագիր։
 2. Գրանցեք դրա CPU/RAM օգտագործումը, բացեք նոր փաստաթուղթ
    կամ բրաուզերի ներդիր ու կրկին դիտեք։
 3. Գրեք երեք փաստ և մեկ ենթադրություն՝ հստակ տարբերակելով
    դրանք։

Կատարման չափանիշներ: Փաստերը չեն ներկայացվում որպես
չստուգված պատճառահետևանքային եզրակացություններ։

C. Գ. Ծառայություններ և ավտոմեկնարկ

 1. Task Manager → Startup apps բաժնում գտեք երկու հայտնի տարր։
 2. Եթե թույլատրված է, services.msc -ով կարդացեք ծանոթ
    ծառայության նկարագրությունը։

---

3. Փակեք պատուհանները՝ առանց ծառայություններ դադարեցնելու
    կամ կարգավորումները փոխելու։

Կատարման չափանիշներ: Կատարվել է միայն դիտարկում, ոչ
փոփոխություն։


Ինքնուրույն առաջադրանք

Բացատրեք՝ ինչ է տեղի ունենում ծրագրի պատկերակը բացելիս և
ինչպես է ՕՀ-ն տրամադրում CPU ու RAM ռեսուրսներ։


Տնային աշխատանք

Կազմեք Windows-ի համառոտ հաշվետվություն՝ տարբերակ, build,
գործընթացի դիտարկում և ֆոնային ծառայության օրինակ։ Մի գրանցեք
անձնական նույնացուցիչներ։

Լրացուցիչ առաջադրանք: Համեմատեք բարձր CPU օգտագործման
երկու հնարավոր պատճառ և առաջարկեք անվտանգ տարբերակման
եղանակ։
