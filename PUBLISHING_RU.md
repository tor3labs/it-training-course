# Публикация курса

## Текущее состояние

- Загружены восемь учебных занятий первого этапа на русском, армянском и английском языках.
- Добавлены материалы самопроверки, шаблоны, ответы и разделы будущих этапов 2–5.
- Автоматическая сборка `mkdocs build --strict` проверена в GitHub Actions и завершилась успешно.
- GitHub Pages ещё необходимо активировать: доступная интеграция не имеет разрешения `create Pages site`.

## Как включить сайт

1. Открыть `https://github.com/tor3labs/it-training-course/settings/pages`.
2. В блоке **Build and deployment → Source** выбрать **GitHub Actions**.
3. Открыть вкладку **Actions** и запустить workflow **Deploy multilingual training site** через **Run workflow**; при необходимости можно сделать новый коммит для автоматического запуска.
4. После успешного выполнения сайт должен быть доступен по адресу `https://tor3labs.github.io/it-training-course/`.

## Формат и ограничения текущей загрузки

Веб-страницы уроков перенесены из собранных печатных пособий. Полные исходные Markdown-файлы, SVG, PDF и DOCX находятся в отдельно подготовленном исходном ZIP-архиве. Чтобы сохранить исходное форматирование и добавить печатные пособия в GitHub, нужно дополнительно загрузить эти файлы из архива (обновив существующие файлы по совпадающим путям).

Не публикуйте финансовые документы, реальные имена и другие личные данные обучающихся. На публичном GitHub Pages все материалы доступны для просмотра без авторизации.
